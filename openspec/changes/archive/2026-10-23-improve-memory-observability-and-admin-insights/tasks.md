- [x] 2.4 Reuse stored embedding vectors for term recall instead of re-embedding candidates: in `lib/agent_db/application/memories.ex` and `lib/agent_db/adapters/sqlite.ex`, load the candidate rows' vectors from the active `vec_nodes_<dim>` table and rank against them, falling back to confidence ordering and reporting that semantic ranking was not applied when the vectors are absent or their dimension differs from the query's. - [x] 2.5 Bound the memory conflict read's work: in `lib/agent_db/adapters/sqlite.ex`, load candidate vectors in a single query rather than one per memory, compare them in bounded batches, and report that conflicts cannot be evaluated when there are too few vectors to compare rather than reporting an empty verdict. - [x] 2.6 Report memory failures as classified errors rather than empty results: in `lib/agent_db/application/memories.ex` and `lib/agent_db/application/status.ex`, ensure a failed store read returns a classified error and an unavailable model or vector index reports that the work could not be performed, instead of an empty list. Verify with a test that forces a store read failure and asserts the classified reason.
